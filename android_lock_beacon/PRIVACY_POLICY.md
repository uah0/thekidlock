# Политика конфиденциальности BLE Lock

Дата редакции: 19 августа 2026 года.

BLE Lock управляет совместимым замком ESP32 через Bluetooth Low Energy и
локальную сеть.

## Какие разрешения используются

- Bluetooth — поиск, подключение и обмен данными с замком.
- Ближайшие устройства Wi-Fi — создание пользователем локальной точки доступа
  для настройки замка на Android 13 и выше.
- Уведомления — отображение состояния фоновой службы, если пользователь их
  разрешил.

Разрешения используются только для функций, запущенных пользователем, либо для
работы включённого автоматического режима замка.

## Передача и хранение данных

Приложение не отправляет данные пользователя на сервер разработчика, не
использует рекламу и аналитические службы и не продаёт данные. Настройки
приложения хранятся локально на телефоне. Настройки замка передаются по
защищённому BLE-соединению и хранятся в ESP32.

При открытии Web UI приложение передаёт браузеру локальный адрес ESP32.
Содержимое локальной сети и пароль Wi-Fi разработчику приложения не передаются.

Удаление приложения удаляет локальные данные Android. Данные, ранее сохранённые
в ESP32, удаляются средствами самого замка.

## Контакт

По вопросам конфиденциальности используйте контакт разработчика, указанный на
странице приложения в Google Play.
