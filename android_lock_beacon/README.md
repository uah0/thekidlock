# TheKidLock Android

Android-приложение для ESP32 BLE Lock: телефон публикует AUTO-маяк и единый
служебный маяк, ESP32 подключается к защищённому GATT-серверу телефона.

- Kotlin, Android Views.
- minSdk 26, target/compileSdk 36.
- Сборочный скрипт использует JBR Android Studio и настроенный Android SDK.
- Состояние Gradle/Android хранится в корневых `.gradle-codex` и `.android`.

Сборка из корня репозитория:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\build-android.ps1
```

Foreground Service обслуживает один набор рекламы и защищённый GATT-сервер.
AUTO использует маркер `0x01`; служебные операции Wi-Fi/Web IP/постоянное открытие
используют один маркер `0x83` и разные GATT-характеристики. Кнопка постоянного
открытия показывает ожидание до подтверждения ESP; Wi-Fi для неё не требуется.
Сначала запрашивается текущий режим, затем отправляется явная установка состояния,
поэтому повтор после потери ответа не инвертирует команду. Таймаут запроса — 30 с.
Перед первичной регистрацией нужно открыть окно регистрации на ESP32.
Подробности: [план и контракт служебного маяка](../SERVICE_BEACON_PLAN.md).
