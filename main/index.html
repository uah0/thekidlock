BLE Lock S3 — этап 3

Рабочий веб-интерфейс встроен строкой INDEX_HTML в файл web_ui.c.

ESP32-S3 подключается к сети Cisco в режиме STA и получает IP по DHCP. Точка доступа устройством не создаётся.

Бипер

GPIO назначается через веб-интерфейс и сохраняется в NVS. Начальное значение — GPIO4.

Управление активным нулём: уровень 0 включает звук, уровень 1 выключает.
