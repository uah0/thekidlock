## Test 3 — экран выключен 2 часа, 2026-10-01

Источники: `artifacts/android-ble-foreva-export-20261001.txt` (экспорт с телефона) и `artifacts/esp32-20261001-203809.log` (непрерывная запись Serial). Телефон: Xiaomi `2510DRA23E`, Android 16 / SDK 36. Device ID `668D5854`, Session ID `5B414848`. Установленный APK использовал `ADVERTISE_MODE_LOW_POWER`, `ADVERTISE_TX_POWER_ULTRA_LOW`.

| Экран выключен | 20:38:25.955–22:39:00.095 +03:00, 2 ч 00 мин 34,140 с |
| Ручная остановка сервиса | 22:39:05.289 +03:00 |
| Первый–последний пакет текущей session по ESP32 | boot_ms `1057364`–`8288744`, 2 ч 00 мин 31,380 с |

| Средний интервал между принятыми пакетами | 1477,6 мс |
| Максимальный завершенный интервал | 9185 мс |

В ESP32-логе 724 полных блока STAT для этой session; они шли с интервалом около 10 секунд. За время опыта не видно повторного подключения Serial, перезагрузки ESP32 или смены Session ID. В Android-логе между `SCREEN_OFF` и `SCREEN_ON` нет перезапуска сервиса или события выключения Bluetooth. Темп приема по последовательным получасовым участкам: примерно 40,3; 40,2; 41,3; 40,7 пакета/мин. За завершенные 60-секундные окна после начального прогрева наблюдалось 31–50 пакетов.

**Итог:** двухчасовой тест устойчивости при выключенном экране пройден: ESP32 продолжала получать пакеты той же session, максимальный наблюдаемый разрыв между приемами — 9,185 с. `Missing_gt_*` считает интервалы приема, а не достоверное количество пропущенных телефонных передач. По этим логам нельзя определить каждый фактический момент передачи радиопакета, вход телефона в Doze, состояние зарядки или его неподвижность. Тест 8 часов пока не проводился.

После сохранения обоих логов установлен APK с выбором `LOW_POWER`, `BALANCED` и `LOW_LATENCY`: `artifacts/ble-foreva-modes-next.apk` (тот же SHA-256, что у собранного debug APK). Перед установкой записаны `accelerometer_rotation=0` и `user_rotation=0` в `artifacts/android-rotation-before-20261001-224447.json`; после установки оба значения восстановлены и проверены. Advertising для нового теста не запускался.
