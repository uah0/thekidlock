# План деморолика TheKidLock

Цель: показать реальное приложение на физическом телефоне, управляющее настоящим
замком. Интерфейс приложения и Web UI не изменять. Симулятор не используется.

## 1. Подготовить демонстрационный стенд

- Подключить телефон по Wi-Fi ADB, проверить доступность и разблокировать экран.
- Проверить установленную версию, BLE, Wi-Fi и доступность MQTT брокера.
- Убедиться, что замок работает; назначить человека для открытия/закрытия двери.
- Сохранить исходные параметры, которые будет менять сценарий: автооткрытие,
  мощность BLE, удержание открытого, импульс бипера, задержка выхода из зоны.
- Прочитать и записать accelerometer_rotation и user_rotation; после демонстрации
  восстановить их. Выключить уведомления для чистой записи, сохранив исходный режим.
- Не показывать пароли, идентификаторы телефонов и персональные данные. Не менять
  брокер, Wi-Fi, регистрацию телефонов и калибровку рабочего замка ради ролика.

## 2. Составить последовательность кадров

Ориентировочная длительность 2–3 минуты; точные паузы определить пробным проходом.

| Эпизод | Действия на телефоне | Действия у замка / результат |
| --- | --- | --- |
| Главный экран | Пауза 4 секунды, показать основные кнопки | Замок закрыт |
| Автооткрытие | Включить режим, показать и переместить регулятор мощности BLE | Показать настройку, вернуть мощность |
| Удержание открытого | Включить «Оставить замок открытым», затем выключить | Реальное разблокирование и возврат |
| Настройки замка | Открыть панель, показать uptime и доступные настройки | Получены реальные данные |
| Звуковой сигнал | Изменить длительность импульса; пауза на тест | Если нужен слышимый звук, внешняя аудиозапись |
| Задержка выхода | Передвинуть ползунок, показать значение, вернуть исходное | Настройка сохранена штатным способом |
| Мастер калибровки | Показать вход и первый шаг, отменить без сохранения | Полное прохождение — отдельный дубль на подготовленном стенде |
| Интернет-открытие | Вернуться на главный экран, отключить автооткрытие, нажать открыть | Оператор открывает и закрывает дверь; показать все пять статусов |
| Завершение | Главный экран, пауза 4 секунды | Дверь закрыта и заперта |

Открытие настроек использует обычный доступ приложения к настоящему замку.
Если для интернет-команды необходимо закончить локальный сеанс, сценарий ждёт
его штатного завершения. Не заменять реальные статусы таймерами и не рисовать их.

## 3. Реализовать управление через ADB

Один проектный PowerShell-скрипт запускает сценарий, записывает журнал и управляет
записью экрана. UIAutomator dump используется для поиска элементов по resource-id,
тексту или content-description. Для WebView/ползунков допускаются координаты,
полученные из текущего размера экрана и проверенные на пробном проходе.

Каждый шаг: проверить ожидаемый экран, выполнить действие, дождаться результата,
выдержать паузу для чтения. При неожиданном экране или таймауте остановить сценарий,
сохранить кадр/дамп и журнал. Не продолжать слепые нажатия.

Для физического открытия/закрытия двери предусмотреть паузу оператора с продолжением
из консоли. Использовать ручное сопровождение пробного прохода; затем выбрать
паузы для чистого дубля. Статусы интернет-команды проверять по фактическому экрану.

## 4. Записать и собрать ролик

Сначала проверить запись коротким тестом через Android screenrecord и скопировать
MP4 через adb pull. Если возможности телефона ограничивают длину или качество,
записать отдельные эпизоды и соединить их. Возможность записи звука проверять отдельно:
не считать, что screenrecord запишет бипер настоящего замка.

Записать пробный дубль, проверить читаемость, паузы, отсутствие уведомлений и секретов.
Затем сделать чистовой дубль. Монтаж: обрезка технических пауз, короткие подписи
эпизодов при необходимости, без изменения показанных состояний приложения.

## 5. Восстановить и проверить

Вернуть сохранённые настройки приложения и замка, режим уведомлений и ориентацию.
Проверить, что дверь закрыта и заперта и автооткрытие имеет исходное состояние.
Сохранить сценарий, журнал выполнения и финальный MP4 в отдельном каталоге артефактов.

## Критерии готовности

Ролик показывает главный экран, мощность BLE, настройки замка и реальные этапы
интернет-открытия. Все действия выполняются штатным интерфейсом. Исходные настройки
восстановлены. Сценарий останавливается при ошибках и повторяется на этом телефоне.
