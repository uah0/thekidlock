# BLE Lock ESP32-S3

Прошивка phone-only BLE-замка для ESP32-S3 с Web UI, OTA, RGB-индикацией и
бипером. Телефон подключается к GATT Server `BLE Lock`, проходит LE Secure
Connections Pairing/Bonding и отправляет защищённую команду `OPEN`.

## Безопасность и регистрация

- Разрешено одно BLE-соединение и до 10 сохранённых bonds.
- Новый телефон можно привязать только в 60-секундном окне, открываемом из Web UI.
- Используется Secure Connections Just Works (`NO_IO`, без MITM); legacy pairing
  и режим SC-only отключены.
- Bonds сохраняются в NVS и удаляются из Web UI по одному или все сразу.
- Команда открытия принимается только от encrypted и bonded соединения при
  достаточном RSSI.

## Замок

Замок — fail-safe электромагнит на GPIO 3: для запирания питание подаётся
постоянно, команда открытия снимает питание. Логический уровень GPIO,
соответствующий открытому замку, выбирается в Web UI и сохраняется в NVS.

После `OPEN` таймер А удерживается достаточным RSSI телефона. Таймер «Долго
открыт» не продлевается и принудительно закрывает замок. После этого повторное
открытие блокируется до трёх слабых измерений RSSI или отключения телефона.

## Web UI

Интерфейс показывает BLE-соединение, encryption, bonding и RSSI; позволяет
настроить RSSI, оба таймера, активный уровень GPIO 3 и GPIO бипера, открыть окно
регистрации, управлять bonds, выполнить тест открытия и загрузить OTA.

## Сборка

Проект рассчитан на ESP-IDF 5.4:

```powershell
idf.py build
idf.py flash monitor
```

Перед подключением силовой цепи проверьте мультиметром выбранную полярность:
GPIO ESP32 не должен питать электромагнит напрямую, необходим подходящий ключ и
защита от выброса самоиндукции.
