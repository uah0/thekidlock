# TheKidLock

TheKidLock — электронный замок на ESP32-S3 с Android-приложением. Замком можно управлять рядом по Bluetooth или удалённо через интернет с помощью MQTT-брокера.

## Возможности

- Автооткрытие при появлении зарегистрированного телефона в зоне замка.
- Открытие по кнопке и режим «Оставить замок открытым».
- Удалённое открытие через интернет с отображением этапов выполнения команды. Команда доступна телефону владельца.
- Виджет Android для переключения автооткрытия без открытия приложения.
- Настройки замка в Web UI: зона открытия, задержка закрытия, звуковое подтверждение и адрес MQTT-брокера. Брокер можно выбрать из списка или ввести вручную.
- Мастер калибровки по двум положениям: закрытая дверь и открытая дверь.
- Проверка обновлений приложения и прошивки при открытии экрана приложения.

## Обновление

Приложение скачивает новую прошивку с GitHub и хранит её на телефоне. Пользователь запускает установку кнопкой «Установить обновление» в настройках замка; прошивка передаётся замку только с телефона.

Обновление Android-приложения предлагается строкой «Есть обновление». Установку APK подтверждает пользователь в штатном установщике Android.

Прошивка по ссылке предназначена для OTA совместимых, уже подготовленных замков. Для первоначальной установки нового замка требуется отдельная подготовка.
