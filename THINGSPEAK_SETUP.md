# Настройка журнала ThingSpeak

ThingSpeak используется только для HTTPS-журнала событий. Прежние MQTT-команды и утилита их отправки удалены; интернет-открытие настраивается отдельно в MQTT_SETUP.md.

Создать закрытый канал со следующими полями:

| Поле | Содержание |
| --- | --- |
| field1 | MAC замка |
| field2 | инициатор |
| field3 | событие |
| field4 | источник |
| field5 | UTC в микросекундах |
| field6 | ID события |
| field7 | результат |
| field8 | uptime/boot |

В панели ThingSpeak Web UI указать номер канала, Read API key и Write API key, включить журнал. Пустые поля ключей сохраняют прежние значения. При непустой очереди смена канала запрещена. Существующий канал/ключи сохраняются при миграции старой конфигурации.

Время события — field5, а не created_at; точность определяется синхронизацией SNTP. События без восстановимой UTC-опоры помечаются unsynced. Очередь ограничена: 32 сохранённые записи плюс RAM; при длительном отсутствии облака возможны потери новых событий со счётчиком. Статус панели показывает UTC, очередь, потери и состояние отправки.

Bulk-журнал читается через HTTPS. MQTT-управление, каналы команд/результатов и MQTT credentials в этой панели отсутствуют.
