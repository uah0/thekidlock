# Начальная прошивка нового замка через USB

`thekidlock-usb-bootstrap.bin` — единый образ для **нового, аппаратно не защищённого ESP32-S3 с флеш-памятью 4 МБ**. Его версия и SHA-256 указаны в `manifest.json` и `thekidlock-usb-bootstrap.sha256`.

Образ содержит загрузчик по адресу `0x0`, таблицу разделов по `0x8000`, начальные OTA-данные по `0xF000` и подписанное приложение по `0x20000`. NVS в промежутке между разделами заполнена `0xFF`. Запись этого файла поверх существующего устройства стирает настройки NVS. Он не предназначен для восстановления уже аппаратно защищённого замка.

Этот профиль не включает Secure Boot, аппаратное Flash Encryption или прожиг eFuse. После первой загрузки владелец регистрирует телефон и выполняет калибровку через приложение. Следующие обновления приложение скачивает с GitHub и передаёт замку по кнопке Web UI.

Для подготовки новой версии из корня проекта:

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\build-esp32.ps1
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\usb-bootstrap\build.ps1
```

Когда будет дано отдельное указание на запись в новый чип, образ записывается с адреса `0x0` с помощью `esptool` и выбранного USB-порта. Физическая запись и проверка первого запуска пока не проводились.
