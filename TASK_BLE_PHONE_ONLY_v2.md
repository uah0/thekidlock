# TASK_BLE_PHONE_ONLY.md (обновлённая редакция)

## Изменения по сравнению с предыдущей версией

1. Замок открывается только телефоном по BLE GATT.
2. Поддержка отдельных BLE-маяков полностью удаляется.
3. Исполнительный выход замка — GPIO 5.
4. Используется только стандартный BLE Pairing/Bonding (LE Secure Connections).
5. Bonds сохраняются во внутренней NVS NimBLE.
6. Внешняя память не используется.
7. Максимальное количество зарегистрированных телефонов — 10.
8. Одновременно допускается только одно активное BLE-соединение.
9. При попытке зарегистрировать 11-й телефон регистрация должна быть отклонена
   с предложением удалить существующий bond через Web-интерфейс.
10. Автоматическое удаление существующих bonds запрещено.
11. В Web-интерфейсе необходимо отображать список зарегистрированных телефонов
    (насколько это позволяет API NimBLE) и предоставить возможность удаления
    отдельного bond либо всех bonds.
12. Все команды открытия (BLE и тест из Web) должны использовать единый интерфейс
    управления замком, который управляет GPIO 5.

Остальные требования остаются такими же, как в предыдущем техническом задании:
- Wi-Fi, OTA и Web-интерфейс сохранить;
- использовать один экземпляр NimBLE Host;
- реализовать GATT Server;
- окно регистрации 60 секунд;
- проверять encryption, bond и RSSI перед OPEN;
- после каждого этапа выполнять сборку и обновлять AUDIT.md,
  CHANGELOG.md и TEST_REPORT.md.
