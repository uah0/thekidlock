# Архив материалов вне сборки

Здесь сохранены предыдущие результаты сборки и публикации, диагностические записи, материалы демонстрационного видео, исходники графики и записи проверок Android. Это архив, а не часть активной сборки.

Исходники ESP находятся в `../main` и `../components`, Android — в `../android_lock_beacon/app/src`. Сборка запускается из корня `../build-esp32.ps1` и `../build-android.ps1`. Каталог `production` содержит старые релизные комплекты и подготовленный USB-образ 10.0.560. Каталог `build-finalize-existing` содержит старый машинозависимый CMake-кэш.

В `demo` лежат сценарий и план демонстрационного видео; в `android-install-records` — записи ориентации Android перед старыми установками APK.
