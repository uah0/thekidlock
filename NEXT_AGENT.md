## Важные решения пользователя

- Замок — электромагнит fail-safe: ток подаётся постоянно для закрытия.
- Активный уровень открытия GPIO 5 настраивается в интерфейсе замка.
- Телефон должен автоматически открывать дверь из кармана, с выключенным экраном.
- Приложение должно быть установлено на телефон и работать в фоне.
- Целевая реализация описана как Android Foreground Service.
- Старый bond должен удаляться на ESP32 вручную; автоматическое удаление запрещено.

## Техническая граница

Приложение пишет только `OPEN` в существующий `LOCK_COMMAND`. Решение об открытии
остаётся на ESP32. Текущего GATT достаточно для A1–A4; расширение GATT для полной
BLE-панели относится к A5 и требует отдельного проектирования.
