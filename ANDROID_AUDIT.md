# Аудит Android UI-кнопок

## AUTO и мощность маяка

- `createAutoModeControl()` собирает существующую AUTO-кнопку и горизонтальный `HorizontalLevelSlider` в одном `FrameLayout`.
- Длительное нажатие на кнопку и контейнер удалено. Ползунок постоянно виден в прежнем нижнем слое панели, поверх кнопки; обычный тап по свободной верхней области AUTO по-прежнему переключает режим.
- Настройка мощности по-прежнему сохраняется в существующем `LockSettings` и передаётся `BleLockService`.

## Интернет-открытие

- Существующий `InternetOpenProgressButton` и его event flow сохранены.
- Кнопка разделена горизонтально: верхняя половина постоянно показывает название, нижняя содержит пять цветовых сегментов прогресса.
- Этапы по-прежнему отображают ответы и физические статусы замка; ошибка мигает красным в зоне прогресса. Внешний размер View и клик-обработчик не менялись.

## Подпись и обновление APK

- `build-android.ps1` направляет `ANDROID_USER_HOME` и `user.home` в основной каталог проекта; debug APK подписывается ключом `C:\Dev\ble-main-build216\.android\debug.keystore`.
- Этот ключ должен оставаться на месте между сборками. Его текущий сертификат SHA-256: `36d8b6f9655e42c3810e495ce676e7cff0e65f0d2c1e3a74a284a4cc09f727c7`.
- Повторяющийся отказ обновления вызван приложением на телефоне, установленным из другой сборочной папки и подписанным сертификатом `1f629c79aac5d699c44873c364fe240e6f57bb7a5e92c81202af1ee251698ade`. С разрешения пользователя оно удалено, build 231 установлен с ключом основной папки; повторный `adb install -r` прошёл. Последующие APK из этой основной папки используют тот же сертификат.
