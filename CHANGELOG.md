# Журнал текущей версии

## Android-кнопки и автосохранение крутилок — 12.10.2026

Кнопке «Отозвать ключи» добавлена иконка в стиле соседних действий; основные
кнопки получили более заметную окантовку и объём. Все крутилки Web UI
центрированы. Значения автоматически записываются в NVS при завершении
изменения, нижняя кнопка общего сохранения удалена.
Опубликованы Android 1.0.385 и ESP32 10.0.550.

## Android Web UI — тактильная отдача крутилок — 12.10.2026

Круговые регуляторы в окне Web UI вызывают системный Android haptic tick через мост WebView на каждом тактильном делении; для обычного браузера сохранён `navigator.vibrate` fallback.

## Web UI — нативная прокрутка и жесты крутилок — 12.10.2026

Убрана отдельная полоса прокрутки; страницу можно прокручивать вертикальным жестом по экрану. Крутилки фиксируют направление жеста: вертикальный прокручивает страницу без изменения настройки, горизонтальный меняет её.

## Web UI — ширина прокрутки и размер крутилок — 12.10.2026

Сенсорная полоса прокрутки расширена с 36 до 72 px, с сохранением свободной области справа от содержимого. Крутилки увеличены с 173 до 225 px (около 30%).

## Web UI — крутилки +20% и видимая полоса прокрутки — 12.10.2026

Размер крутилок увеличен с 144 до 173px. Справа добавлена видимая дорожка с бегунком, показывающим позицию и размер области просмотра; касания на дорожке по-прежнему прокручивают всю страницу.

## Android — обычный размер шрифта списка отзыва ключей — 12.10.2026

Убран масштаб 0.5× у имени и адреса телефона в списке отзыва ключей. Используется стандартный размер текста Android AlertDialog (18sp на текущем SDK), близкий по высоте к значку чекбокса.

## Web UI — левая позиция крутилок, полоса прокрутки и тактильный отклик — 12.10.2026

Крутилки выровнены влево. Сенсорная прокрутка страницы работает через прозрачную область справа во всю высоту экрана. На делениях вызывается короткая вибрация; добавлено Android-разрешение `VIBRATE` для WebView. Диапазоны и отправка параметров остались прежними.

## Web UI — круговые регуляторы — 12.10.2026

Четыре ползунка заменены круглыми крутилками по образцу `knob.html`. Вертикальный свайп прокручивает страницу, горизонтальный поворачивает регулятор; колесо мыши не меняет значение. Значения по-прежнему проходят через прежние обработчики Web UI; диапазоны, логарифмическая регулировка звука и запросы сохранения сохранены.

## 12.10.2026 — короткие MQTT-топики

- Адрес команды изменён на `j<MAC>/0yF`, ответа — на `j<MAC>/7qK`; для текущего замка это `ja0f262f114b8/0yF` и `ja0f262f114b8/7qK`. Обновлены формирование префикса в `main/mqtt_config.c`, подписки и публикации в `main/cloud_commands.c`, адреса в Android `InternetOpen.kt`.
- При подключении замок отменяет сохранённую у брокера подписку на старый `locks/<MAC>/command` и очищает старое retained-сообщение `locks/<MAC>/state`. Стенд `tools/test-cloud-auth.py` обновлён для проверки игнорирования старого топика.
- Прошивка 10.0.511 установлена через OTA и опубликована как последний ESP-релиз. Совместимое приложение опубликовано как 1.0.371.

## 12.10.2026 — шифрование интернет-открытия

- MQTT `/command` и `/result` передают JSON внутри AES-128-GCM; ключи направлений выводятся из BLE LTK стандартным HKDF-SHA256. Внешний конверт содержит только версию, nonce и шифртекст с тегом.
- Замок отклоняет прежние открытые MQTT-команды. Проверки владельца, HMAC, срока действия, монотонного ID и PUBACK сохранены.
- Неиспользуемая публикация `/state` удалена; при подключении замок очищает старое retained-сообщение брокера.
- Размер задачи MQTT-команд увеличен для буферов шифрования. Изменены `main/cloud_commands.c`, новые `main/cloud_crypto.c/.h`, `main/CMakeLists.txt`, `sdkconfig.defaults`, Android `InternetOpen.kt`, новый `InternetCrypto.kt`, `app/build.gradle.kts` и `InternetCryptoTest.kt`.
- Шифрованная OTA 10.0.509 установлена на текущий замок. Совместимое приложение опубликовано как `app-v1.0.370`.
- Обновлён стенд `tools/test-cloud-auth.py` под новый конверт MQTT; 47 сценариев пройдены.
- Прошивка `esp-v10.0.509` опубликована как последний ESP-релиз с прямыми ссылками в описании; предыдущий релиз удалён.
