# Готовый второй USB-образ

Собирать образ вручную не нужно. Готовый файл: `thekidlock-usb-final.bin` в этой папке. Это полный образ размером 4 МБ для ESP32-S3 с флеш-памятью 4 МБ; адрес записи — `0x0`.

Порядок использования: записать начальный образ из `usb-bootstrap`, проверить замок, установить и проверить OTA 10.0.578 с GitHub. После проверки записать этот готовый второй образ. Он стирает тестовую конфигурацию: NVS и раздел ключей пусты, клиент настраивает замок заново. Снимок первой прошивки и сохранение NVS не нужны.

Во втором образе включены Secure Boot V2, Flash Encryption Release, зашифрованная NVS и отключение ROM Download. При первом запуске создаются индивидуальные ключи устройства. Этот запуск необратимо меняет eFuse и закрывает ROM Download. Записывать образ и запускать его можно только после отдельного явного разрешения на защиту конкретного чипа, согласно `AGENTS.md`.
