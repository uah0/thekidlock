# Фабричные профили и безопасность — 10.10.2026

## Текущий защищённый замок

Установлена 10.0.438: Secure Boot V2, Flash Encryption Release, NVS HMAC KEY4,
OTA rollback/anti-rollback; ROM Download отключён после успешного OTA self-check.
Рабочий signed/encrypted комплект сохранён в production/esp-10.0.438/.
Свидетельства установки и публикации: production/verification/.

## Ключи и инструменты

Секреты и фабричные резервные копии: .security/. Не публиковать эту папку.
Сборка: build-esp32.ps1 -Action build -Profile finalize-existing.
OTA контейнер: tools/prepare_encrypted_ota.py; публикация: tools/publish_esp32_release.py.
Фабричная подготовка: tools/prepare_factory_security.py — только офлайн,
существующая версия рассчитана на HMAC KEY2 и миграцию известного устройства.
Не считать её готовым workflow пустого нового замка с текущим OTA KEY4.

## Новый замок

Не загружать сохранённый finalize-existing комплект на пустой ESP как
универсальную первичную прошивку. Согласовать NVS key slot, начальный provisioning,
калибровку и первоначальную OTA загрузку согласно FACTORY_BOOTSTRAP_PLAN.md.

Secure Boot, Flash Encryption Release, HMAC/eFuse, блокировка JTAG/ROM и других
интерфейсов выполняются только после отдельного явного разрешения пользователя
на конкретную операцию и конкретное устройство. Предыдущее разрешение текущего
замка не распространяется на новые. До разрешения сохранять восстановление.
Обычный build-esp32.ps1 запрещает flash/flash-monitor для фабричных профилей.

## После очистки

Каталоги сборки удалены; следующая сборка создаст их заново. Для сравнения с
установленной 10.0.436 использовать сохранённый комплект, а не результат новой
сборки: счётчик версии автоматически увеличивается.

С версии 10.0.438 файл получает только Android-приложение. ESP принимает encrypted
OTA из private storage телефона по кнопке Web UI; прямой GitHub downloader отключён.
